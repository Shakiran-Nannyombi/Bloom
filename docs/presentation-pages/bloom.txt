System Architecture
Built for reliability: One shared device · Multiple trusted adults · AI-guided support


  Facilitator Layer (Mobile App)
  Flutter mobile app on shared device per school/household · Offline content caching · Lesson booklets & conversation scripts



  API & Logic Layer
  Node.js / Express REST API · Automated mentor-matching engine · User management & referral workflow handling



  AI Layer
  Safety-tuned AI model · Learning support & conversation guidance · Live Q&A & Luganda/English translation



  Data Layer
  PostgreSQL for user records & mentor databases · Firebase real-time sync · End-to-end encrypted storage
Why Bloom Is Different

We are not building another app that simply
gives girls information.
We are strengthening the adults around them.

Bloom focuses directly on the adults girls already know and trust:

    Parents & Guardians at home

    Teachers in schools

    Trusted Community Leaders


  Because sometimes the biggest barrier is not access to information, it
  is having someone confident enough to start the conversation.
